# vllm-strix-halo

This repository contains the ROCm-enabled vLLM build and ZAYA1-8B support work for the AMD Strix-Halo / AI MAX+ 395 machine.

## Useful docs

- docs/zaya_rocm_serve.md — how to start the vLLM server for ZAYA1-8B on ROCm
- docs/zaya_rocm_repro.md — step-by-step reproduction guide
- docs/zaya_rocm_repro.sh — shell script version of the reproduction steps
- docs/zaya_rocm_debug.md — debugging notes and comparison notes against Zyphra's zaya1-pr branch

## What this repo is for

- Zaya1 support in vLLM on ROCm
- AMD Strix-Halo / gfx1151 validation
- reproducible build and serve instructions for the local environment
